================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "error: repository not empty"
SOLUTION:
rm -rf .git
git init
(start over from Command 2)

PROBLEM: "fatal: could not read Username"
SOLUTION:
- You need a GitHub Personal Access Token
- Create one at: https://github.com/settings/tokens
- Select "repo" scope
- Use the token as password (not your GitHub password)

PROBLEM: "fatal: not a git repository"
SOLUTION:
- Make sure you ran "git init" first
- Make sure you're in the EventLog directory

PROBLEM: "remote origin already exists"
SOLUTION:
git remote remove origin
git remote add origin https://github.com/Alvin366/EventLog.git

PROBLEM: "error: src refspec main does not match any"
SOLUTION:
- Your branch isn't named "main"
git branch -M main
git push -u origin main

PROBLEM: "Permission denied (publickey)"
SOLUTION:
- You're using SSH instead of HTTPS
- Switch to HTTPS:
git remote set-url origin https://github.com/Alvin366/EventLog.git
git push -u origin main
