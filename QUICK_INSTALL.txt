COPY & PASTE THESE COMMANDS:

Step 1: Navigate to custom components
    cd /config/custom_components

Step 2: Clone from GitHub
    git clone https://github.com/Alvin366/EventLog.git temp-repo

Step 3: Copy component files
    cp -r temp-repo/custom_components/eventlog .
    rm -rf temp-repo

Step 4: Verify installation
    ls -la eventlog/
    (should show 4 files)

Step 5: Restart Home Assistant (via UI)
    Settings > System > Restart Home Assistant
    Wait 2-3 minutes

Step 6: Check logs (via UI)
    Settings > System > Logs
    Search for: "EventLog v2.0.0-alpha starting"

✅ DONE! Component installed and running.
